## Grid-based распределение

- Главная цель метода — избежать кластеризации (когда все объекты кучкуются в одном углу) и гарантировать, что объекты будут распределены по всей доступной площади максимально равномерно, покрывая все зоны лабиринта.
- Вместо того чтобы случайным образом выбирать позиции из tilePositions (что может привести к их скоплению), вы сначала накладываете на лабиринт виртуальную сетку, а затем размещаете по одному объекту в каждой ячейке этой сетки.

### Пошаговая теория метода

1. Определение границ игрового пространства
   - Первым делом алгоритм вычисляет, в каких границах существует ваш лабиринт. Это делается поиском минимальных и максимальных значений по осям X и Z среди всех позиций тайлов (tilePositions).
2. Создание виртуальной сетки
   - Затем пространство лабиринта делится на виртуальную квадратную сетку размером gridSize x gridSize.
     `gridSize = Ceil(Sqrt(coinCount))`
3. Расчет целевых точек
   - Для каждой ячейки этой сетки вычисляется ее центральная точка (targetX, targetZ).
4. Привязка к навигационной сетке (FindNearestTile)
   - Для каждой целевой точки мы ищем ближайшую реальную позицию тайла из списка tilePositions. Это гарантирует, что монета будет заспавнена именно на проходимой поверхности лабиринта, а не в пустоте или внутри стены.
5. Спавн объектов
   - На последнем этапе мы берем полученный список валидных позиций (gridPositions) и спавним в них наши монеты (в вашем случае — количество монет, не превышающее coinCount).
